# Vector Universe · локальный прототип

Актуальная версия от 23.10.2026: стиль подписи из Flow, солнечная подсветка карточек, покачивание/левитация, три подвеса и движение по комнате при навигации. Главная восстановлена по фотореалистичному макету. WebGL/Three.js и наведение на предметы удалены. Общее решение: [требования к визуальному качеству](../../docs/14_VISUAL_QUALITY_RULES_2026-10-23.md).

Шапка: официальный знак с тем же SVG-кадрированием, что в Flow (0 40 382 180); сам знак поднят для оптического центра, Universe и навигация стоят на общей оси. Цвет подписи #5CA4F3, Futura PT / FuturaPT / Arial, вес 400, пропорция размера шрифта к ширине SVG 34/140. Загруженного Futura PT в Flow нет, поэтому в этой среде оба используют Arial. Разделитель 1 px / 1.28 em по прямой новой просьбе ярче, чем в Flow: #8EBCF4 вместо #BED9FA.

Навигация: короткий переход с ощущением глубины (0.62 с), неподвижная шапка, фон той же комнаты плавно приближается и смещается по-разному для школы, портфолио и выставки (1.15 с). Новая картинка комнаты не создавалась. View Transitions не блокируют нажатия; быстрые переходы выбирают последний hash. При reduced-motion анимаций нет; без API переход остаётся рабочим.

Предметы: лента мягко меняет наклон/ширину, кольца слегка поворачиваются вокруг вертикальной оси, четыре диска левитируют с разной фазой. Поворот колец в плоскости экрана убран. Это имитация на фотографических слоях, без показа обратной стороны и сложной 3D-переделки. Ровно три SVG-подвеса неподвижны: два внешних, один к внутреннему. Маска движущихся колец скрывает центральную нить за большим обручем и не позволяет правой нити заходить на лицевой металл. [Актуальные ассеты и промпт](../artwork/2026-10-23/MOTION_REFINEMENT.md).

## Запуск

```powershell
npm ci
npm run dev
```

Постоянный адрес: **http://127.0.0.1:5187/**. Strict port: адрес не меняется, чужие процессы не останавливаются. Сервер текущей сессии оставлен работающим.

## Готовые сценарии

- **Мой мир:** фотографическая сцена с аркой, лентой, кольцами, стеклом, терраццо, тенями и отражениями. Официальный SVG без рамки; Universe на оси навигации и середины двух строк школы. Медленная анимация слоёв, проходы света по металлу/стеклу, блики и отражённый свет на полу. Карточки при наведении и клавиатурном фокусе освещаются тёплым светом слева, без цветной рамки. Нет WebGL, наведения на предметы, управления камерой, кнопок предметов или кастомизации. При reduced-motion — статичная иллюстрация с тремя подвесами. Главная помещается в экран ноутбука.
- **Портфолио:** поиск, предметы, готовые работы и черновики; несколько файлов, описание, вклад, участники, обложка и ссылка. Запись в IndexedDB завершается до сообщения об успехе. Файлы хранятся как Blob. Перезагрузка сохраняет данные, редактирование не создаёт дубль.
- **Проекты школы:** четыре маркированных примера заданий, поиск/фильтры, подробная задача, чек-лист и настоящие локальные материалы. «Начать проект» создаёт связанный личный черновик. Повторное действие открывает ту же работу.
- **Выставка:** пять подготовленных примеров и отдельный блок своих публикаций; поиск/фильтры, отдельная страница просмотра, участники и вклад, галерея, скачивание и полноэкранный просмотр. «На выставку» у готовой своей работы сохраняет публикацию в IndexedDB; «Снять с выставки» оставляет работу и файлы в портфолио. Черновик и внешний материал не публикуются. Сохранение опубликованной работы как черновика снимает публикацию. Локальная граница указана рядом с действием и в разделе; синхронизации со школой нет. Нет комментариев, оценок или лайков.
- **Показ родителю:** все готовые материалы, включая Египет, без добавления/редактирования, с возвратом. Черновики не показываются в подборке. Раньше фильтр исключал внешний PDF; фильтр исправлен, настоящее авторство и источник сохранены. Это режим просмотра в том же браузере, не отдельный аккаунт и не защита паролем.
- **Сброс:** предупреждает об удалении добавленного и очищает только Universe, возвращая три начальных материала.

Имена не склоняются: «Портфолио · Иван». Компонент Artwork не получает данные работ: файлы, текст и обложки ученика не могут появиться в арке.

## Честные границы

Данные доступны только в том же браузере и по тому же origin. Очистка браузерных данных удаляет личные работы. Нет сервера данных, облака, синхронизации, регистрации, кабинета педагога или публичного деплоя.

PDF.js и worker локальны, PDF открывается лениво с четырьмя миниатюрами. Фото/видео — нативный просмотр. Другие документы скачиваются; Office-редактора нет. HTML-материалы заданий читаются, скачиваются и печатаются.

Исходный PDF **Art History Ancient Egypt**, Michael Leonard / Humanities LibreTexts, 132 страницы на английском, не изменён. Авторство не приписано ученику. [Источник и лицензия страницы](public/assets/history-source.md).

Призма — маркированная иллюстрация без фальшивой кнопки Play. Загруженные настоящие видео воспроизводятся нативным video. Остальные люди, работы, задания и изображения — демонстрационные примеры, без выдачи за факты школы.

Анимация сцены — ограниченное движение фотографических слоёв, а не пространственная ротация 3D-моделей. Системный Arial — доступный fallback; коммерческий FuturaPT не добавлен.

Реставрированные исходники сцены — 1586×992. Экспорты 3200×2006 обеспечивают контролируемое масштабирование и слабое сжатие WebP (quality 98), но не являются нативным 2K/4K. Генератор дважды не выполнил запрошенное разрешение. [Ассеты, точные промпты и размеры](../artwork/2026-10-23/DETAIL_RESTORATION.md).

Админка и настоящие команды с приглашениями пока не реализованы. Утверждённое направление: [админка, публикация и команды](../ROADMAP_ADMIN_TEAMS_2026-10-23.md). Поле участников сейчас — подпись к работе, а не отправка приглашений.

- [Подготовка иллюстрации и промпты](../artwork/2026-10-23/BUILD.md), [дополнительные иллюстрации](../artwork/2026-10-23/CATALOG_PROMPTS.md).

Ассеты включены в проект; для запуска генераторы не нужны. prepare-catalog-assets.cjs извлекает только фотографические области принятых макетов. prepare-materials.mjs создаёт учебные HTML-шаблоны. Тексты, формы, карточки и кнопки — настоящий интерфейс.

## Проверка

```powershell
npm run build
npm run test:browser
```

TypeScript/build и **20 браузерных сценариев** прошли. Тесты используют установленный Microsoft Edge и отдельные контексты, не сбрасывают пользовательское окно. Отчёт: qa/browser-results.json; [визуальная проверка](qa/REVIEW.md).

Главная проверена на 1584×993, 1440×900, 1600×1000, 1280×800, 1650×954, 2061×1186, 2560×1600, 2560×1440 и 1280×720. На этих размерах нет обязательного вертикального/горизонтального скролла главной. На телефоне и длинных страницах прокрутка остаётся по содержимому.
