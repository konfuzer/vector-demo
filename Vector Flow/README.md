# Vector Flow · локальный административный кабинет

Рабочий прототип по согласованным макетам A, заявок администратора и карточки ученика до/после оплаты. Разработка разрешена прямыми поручениями пользователя в продуктовом чате. Все изменения находятся в `Vector Flow/`.

## Открыть

**http://127.0.0.1:5193/**

Запуск из этой папки: `npm run dev`. Vite слушает только `127.0.0.1:5193`, с `strictPort`: занятый порт вызывает ошибку, чужие процессы не завершаются. Текущий процесс и правила повторного запуска — в `RUNTIME.md`.

## Что работает

- **Учредитель:** обзор поступлений и выплат, денежный результат, открытые заявки школы/Club, воронка одной когорты и заполняемость. Графики и показатели открывают соответствующие записи. Раздел экономики показывает структуру выплат и выгрузку CSV.
- **Администратор:** заявки, фильтры, назначение ответственного, следующий шаг, комментарий, история и отмена последней правки. Новая заявка и карточка ученика создаются в том же локальном наборе.
- **Ученики:** персональная карточка, родители и контакты, примечания, график начислений, оплаты, файлы, история. Отдельного раздела семей нет.
- **Оплата:** наличные/перевод, дата, комментарий, необязательное вложение; частичная оплата и распределение большей суммы на следующие начисления. Сумма сверх существующих начислений показана как нераспределённый аванс. Аннулирование записи сохраняет аудит и восстанавливает итоги.
- **Сохранение:** IndexedDB, одна транзакция для записи и вложения. Ошибка записи оставляет форму открытой и не создаёт ложную оплату. Перезагрузка сохраняет изменения; «Действия демо → Сбросить демо» возвращает весь набор Flow к исходному состоянию.

Это локальная демонстрация на вымышленных данных. Настоящих подключений к сайту школы, Club, банкам или почте нет. Переключатель ролей служит для показа и не является авторизацией. Файлы остаются в браузере. Денежный результат — поступления минус выплаты, не бухгалтерская прибыль.

## Короткий показ

1. Открыть обзор учредителя: сентябрь, поступления **4 860 000 ₽**, денежный результат **+740 000 ₽**, **132 / 144** ученика, **16** открытых заявок.
2. Выбрать роль «Мария · Администратор». В заявке Марка Власова выбрать «В работе» без ответственного: форма объяснит отказ. Назначить себя и сохранить — счётчики станут **10 новых / 6 в работе**. Последнее изменение можно отменить в истории.
3. Ученики → Мария Орлова → Оплата → Отметить оплату. Сохранить **50 000 ₽**, при желании приложить демонстрационный PDF из `qa/`. Остаток за сентябрь станет **0 ₽**, появятся запись, файл и история.
4. Вернуться к учредителю: поступления **4 910 000 ₽**, результат **+790 000 ₽**. Нажать на показатель или столбец, чтобы увидеть записи, из которых он складывается.
5. Для повторного показа сбросить демо через меню с многоточием справа в шапке.

## Проверки и материалы

- `npm run build` — TypeScript и сборка.
- `npm test` — доменные проверки денег, распределений, связей и отмены.
- `npm run test:e2e` — реальные сценарии в установленном Microsoft Edge на порту 5193.
- `npm run test:production` — сборка и весь браузерный набор против временного Vite preview на 5199. Скрипт закрывает только созданный им preview. Требуется свободный 5199.
- `node tools/visual-review.mjs` — свежие скриншоты ключевых экранов 1600×1000 и 1280×800 в `qa/`, без изменения данных пользовательской вкладки.

Результаты: `QA_REPORT.md`. Архитектура и модель: `ARCHITECTURE.md`. Принятые изображения: `design/concepts/flow-a-founder-v3.png`, `flow-admin-requests-v1.png`, `flow-student-payment-before-v1.png`, `flow-student-payment-after-v1.png`.

Последнее уточнение по рендерам прочитано в корневом `docs/14_VISUAL_QUALITY_RULES_2026-10-23.md`: сохранять согласованное качество, сравнивать реальные скриншоты, обычные итерации выполнять самостоятельно. Подробности — `design/IMPLEMENTATION_AND_RENDER_FEEDBACK_2026-10-23.md`.

Исторические документы в `design/` фиксируют прежние этапы. Их формулировки «код не создан» и ожидания следующего согласования не описывают текущее состояние и заменены последующими прямыми поручениями пользователя.

## Правки по скриншотам пользователя · 23.10.2026

Flow и голубой разделитель в шапке выровнены по визуальному центру двух строк школьного логотипа; оригинальная геометрия SVG сохранена. Блок «Flow / Всё связано» центрирован, точка удалена. Период и роль используют оформленные меню с выбранным пунктом, Escape, стрелками, Enter и возвратом фокуса.

Период общий для разделов и ролей, сохраняется после перезагрузки. Запомненный маршрут другой роли больше не подменяет месяц. Месяцы новых записей автоматически попадают в список периодов. Нули в месяце без поступлений остаются корректным результатом, а не заменяются выдуманными числами.

Программа Club в заявке только для просмотра. Рабочие поля заявки редактируются. Учредитель сохраняет графики экономики и CSV-выгрузки; администратору экономические графики не добавлялись.

Добавлены шаблон и импорт оплат с предпросмотром: `CSV_IMPORT.md`. Готовый пример: `qa/пример-оплат-демо.csv`. Финальная проверка: **32 доменных теста, 24 браузерных сценария на production-сборке**. Новые скриншоты: `qa/feedback-home-1600.png`, `feedback-import-1280.png`, `feedback-month-1600.png`, `feedback-role-1600.png`. Повторная визуальная проверка: `node tools/feedback-visual-review.mjs`.
