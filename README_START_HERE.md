# VECTOR DIGITAL DEMO | Полный контекст для первого чата Codex

**Версия:** 2026-10-22. **Статус:** DISCOVERY ONLY / READ-ONLY / NO IMPLEMENTATION.

## Что это

Это большой контекстный пакет для нового старта проекта частной школы "Вектор" после неудачной первой попытки разработки Vector Universe. Код старого проекта удалён пользователем намеренно. Архив **не содержит готового React-приложения**, не содержит заданий на немедленное создание кода и не требует установки библиотек.

Задача сейчас - перенести всё содержательное обсуждение в отдельный организационный чат Codex и продолжить уже там. Пользователь хочет обсуждать идеи, смотреть визуальные референсы, находить настоящие макеты в Figma, продумать MCP и skills/агентов. Только после его явного решения можно создавать продуктовые чаты и приступать к реализации.

## После распаковки в КОРЕНЬ пустого проекта

1. Скопируй первое сообщение из `PROMPT_TO_PASTE_IN_FIRST_CODEX_CHAT.md` в **первый организационный чат Codex**.
2. Убедись, что чату доступны локальные файлы проекта. Он должен сначала прочитать `00_MASTER_CONTEXT_PROMPT.md`, `AGENTS.md`, разделы `docs/` и каталог `references/`.
3. Обсудите: какие экраны и бизнес-эффекты нужны, какие визуальные макеты убедительны, нужен ли Figma MCP, какие навыки/агенты полезны, как получать достоверные материалы.
4. До явной команды "можно приступать к разработке" Codex ничего не создаёт и не меняет, кроме того что ты сам распаковал из архива.
5. Не копируй содержимое старых провалившихся промптов. В этом пакете их ошибки только проанализированы.

## Структура

- `00_MASTER_CONTEXT_PROMPT.md` - **большое полное изложение** проекта, истории решений, причин неудачи, желаемого процесса и задач на обсуждение.
- `AGENTS.md` - короткие устойчивые правила для каждого чата.
- `PROMPT_TO_PASTE_IN_FIRST_CODEX_CHAT.md` - сообщение, которое следует вставить в первый чат.
- `docs/` - подробные предметные, продуктовые, визуальные и технические материалы.
- `references/positive/` - восемь оригинальных изображений, присланных пользователем.
- `references/negative/` - скриншоты неудачной реализации, только для антипаттернов.
- `references/aspirational/` - сгенерированный **иллюстративный ориентир**, а не исходник UI.
- `references/Anti AI-slop.txt` - оригинальные строгие требования пользователя.
- `Vector Flow/`, `Vector Universe/`, `Vector Club/` - только справки о границах трёх будущих независимых продуктов. Никакого программного кода там сейчас нет.
- `Demo Hub/` - справка о будущей главной презентационной странице.
- `MANIFEST.json` - список файлов с контрольными суммами.

## Важно о приоритете

Самые свежие сообщения пользователя о концепции имеют приоритет над ранними идеями. Прежние иллюстративные числа и тексты не подтверждают данные реальной школы. Ссылки на официальные сайты и дизайн-сервисы указаны как точки для дальнейшей самостоятельной проверки в Codex.
