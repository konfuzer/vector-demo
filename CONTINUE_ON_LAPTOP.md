# Запуск на ноутбуке

Адаптация 23.10.2026: исправлены широкие экраны Universe и мобильные экраны всех продуктов. Для получения обновления: `git pull --ff-only`, `npm run build`, перезапуск `npm start`. Данные браузера не сбрасывать. Отчёт: `docs/15_RESPONSIVE_QA_2026-10-23.md`.

Обновление 23.10.2026: во всех трёх продуктах рядом с логотипом добавлена кнопка «К проектам Вектора». Локально она ведёт на входную страницу 5190 с учётом VECTOR_PORT_OFFSET, в публичной сборке — на опубликованный Hub. Для обновления существующей копии выполнить `git pull --ff-only`, `npm run build` и перезапустить `npm start`. Новых зависимостей нет. Локальные изменения перед pull не удалять.

Репозиторий: https://github.com/konfuzer/vector-demo . Требуется Node.js 22.12+ (на исходном компьютере 24.18.0), Git и интернет для скачивания и установки зависимостей.

Из корневой папки:

```powershell
npm run setup
npm run build
npm start
```

Открыть http://127.0.0.1:5190/ . Три кнопки ведут на локальные production-сборки: Club 5195, Universe 5187, Flow 5193. Входная страница автоматически получает локальные ссылки, исходный HTML для Cloudflare не меняется. После скачивания, установки и сборки для основных демонстрационных сценариев интернет не нужен. Внешние ссылки на источники потребуют сети. Оставить процесс запуска работающим до конца показа.

## Поручение для Codex на ноутбуке

Прочитай этот файл, AGENTS.md, актуальные решения docs/13_CURRENT_DECISIONS_2026-10-22.md и README каждого продукта. Пользователь поручил перенос и запуск готового проекта для презентации. Это разрешение установить зависимости и запустить существующие приложения; прежние архивные запреты на разработку не препятствуют переносу. Не переделывай дизайн и сценарии, не деплой и не меняй бизнес-логику.

Проверь Node.js и Git. Если проект ещё не скачан, клонируй https://github.com/konfuzer/vector-demo.git в отдельную папку, не поверх другой работы. Выполни в корне npm run setup, npm run build и npm start. Проверь в браузере http://127.0.0.1:5190/, все три перехода, инструкцию и загрузку основных экранов. Дай пользователю локальную ссылку и оставь сервер работать. Не завершай чужие процессы, если порт занят: установи VECTOR_PORT_OFFSET=100 перед npm start, тогда вход будет http://127.0.0.1:5290/ . Не требуй Cloudflare, токенов или доступа к банковским сервисам.

## Контекст встречи

Цель — показать школе «Вектор» несколько прототипов и выбрать полезный оплачиваемый этап работ. Universe — ученическое пространство проектов/портфолио/выставки; Club — подбор дополнительных занятий и сопровождение обращения; Flow — административное рабочее место и обзор учредителя. Подробности продажи Club: CLUB_MEETING_BRIEF.md. Каталог Club уже содержит три демонстрационных направления и четыре академии с официального сайта; условия групп демонстрационные.

В репозитории сохранён контекст в документах, исходники, ассеты, референсы и визуальные концепты. История переписки Codex не переносится через Git автоматически; решения и инструкции переданы файлами. Данные в браузере исходного компьютера также не переносятся: демо начинает с синтетического набора. Настоящих AI, платежей, серверной базы и авторизации нет.

Публичные Cloudflare-адреса ранее были опубликованы и проверены со стороны исходного компьютера, но пользователь сообщил об их недоступности. Для встречи приоритет локальный запуск; не тратить время на повторную публикацию.
