# VECTOR DIGITAL DEMO

Три самостоятельных прототипа для школы «Вектор» и входная страница с инструкцией.

## Запуск на ноутбуке

Требуется Node.js 22.12+ (рекомендуется 24.18.0).

```powershell
npm run setup
npm run build
npm start
```

Открыть **http://127.0.0.1:5190/**. Кнопки откроют три локальных приложения. После установки зависимостей и сборки для основных сценариев интернет не нужен. Закрытие процесса запуска остановит сайты.

Подробная передача и поручение Codex: [CONTINUE_ON_LAPTOP.md](CONTINUE_ON_LAPTOP.md). Актуальные решения: [docs/13_CURRENT_DECISIONS_2026-10-22.md](docs/13_CURRENT_DECISIONS_2026-10-22.md). Подача Club на встрече: [CLUB_MEETING_BRIEF.md](CLUB_MEETING_BRIEF.md).

В репозиторий включены исходники, package-lock, рабочие ассеты, PDF, документы, референсы и концепты. Зависимости устанавливаются через npm ci. Данные демо синтетические; браузерные изменения и история чатов автоматически между компьютерами не переносятся.
