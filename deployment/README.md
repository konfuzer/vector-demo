## Повторная публикация

1. Выполнить `npm run build` в каждой продуктовой папке (Universe — в app/).
2. Из корня выполнить `node deployment/prepare.mjs`.
3. Выполнить `deployment/optimize_pdf.py` Python с pypdf, Pillow и pypdfium2. Только копия для публикации уменьшается с 57 388 824 до 11 594 007 байт; все 132 страницы и текст проверены. Исходный PDF не меняется. Веб-копия имеет отметку об оптимизации, авторство и лицензия сохранены.
4. Последовательно выполнить `npx --no-install wrangler deploy --config deployment/wrangler.<имя>.jsonc` для club, flow, universe и hub. Использовать существующую авторизацию Wrangler, не читать и не копировать OAuth-файл.

Главная исходная HTML-страница уже содержит публичные URL. `prepare.mjs` переносит только собранные ресурсы в assets/; эта папка — единственный публикуемый каталог каждого конфига.
